## Rozpoznanie a enumeracja

Rozpoznanie *(reconnaissance)* zbiera informacje o środowisku przy możliwie najmniejszej ingerencji, często pasywnie. Enumeracja *(enumeration)* aktywnie potwierdza, jakie hosty, porty i usługi rzeczywiście działają. Pierwszym krokiem enumeracji jest ustalenie aktywnych adresów w zakresie, aby dalsze, cięższe skany kierować tylko do istniejących celów.

## Wykrywanie hostów w zakresie

W obrębie jednego segmentu najpewniejsze jest skanowanie ARP, opisane w module warstwy dostępowej. Dla segmentów osiągalnych przez bramę stosuje się wykrywanie hostów narzędziem `nmap` bez skanowania portów.

```bash
sudo nmap -sn -n -e [INTERFACE] [NETWORK]
```

Przełącznik `-sn` ogranicza działanie do wykrywania hostów, bez skanowania portów. Przełącznik `-n` wyłącza rozwiązywanie nazw, dzięki czemu skan nie generuje dodatkowych zapytań DNS. Przełącznik `-e` wskazuje interfejs wysyłki, więc w jego miejsce wpisuje się `[INTERFACE]`, lokalny interfejs. Ostatnim elementem składni jest `[NETWORK]`, zakres adresów w notacji CIDR obejmujący przeszukiwany segment.

```text
Nmap scan report for 192.168.20.10
Host is up (0.0012s latency).
Nmap scan report for 192.168.20.25
Host is up (0.0020s latency).
```

## Granice wyniku

Lista hostów oznaczonych jako aktywne jest podstawą dalszej enumeracji. Brak odpowiedzi nie jest jednak dowodem nieobecności. Host może odrzucać pakiety wykrywające, mimo że działa. Z tego względu adres pominięty na tym etapie, lecz wskazany wcześniej w innym źródle, warto zweryfikować bezpośrednim skanem. Wykrywanie hostów prowadzi się w profilu aktywnym, ponieważ generuje ruch kierowany do badanych adresów.
