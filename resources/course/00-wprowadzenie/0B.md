Praktyczna nauka oceny infrastruktury wymaga środowiska o w pełni kontrolowanych skutkach wykonywanych działań. Laboratorium powinno odwzorowywać podstawowe właściwości rzeczywistej sieci wewnętrznej, a jednocześnie pozwalać na wielokrotne powtarzanie tych samych operacji bez ryzyka naruszenia systemów zewnętrznych.

Minimalne środowisko kursowe obejmuje komputer operatora pod kontrolą systemu Linux, przełącznik zarządzalny z konfiguracją sieci wirtualnych *(VLAN)*, stację roboczą Windows, kontroler domeny *(domain controller)* na potrzeby enumeracji SMB, RPC oraz LDAP, a także serwer z usługami sieciowymi i bazą danych. W dalszych modułach środowisko zostaje rozszerzone o punkt dostępowy sieci bezprzewodowej oraz urządzenie odwzorowujące sprzęt automatyki przemysłowej.

Przykładowa architektura:

```text
                    [ Linux operatora ]
                            |
                    [ Przełącznik / VLAN ]
                            |
          +-----------------+-----------------+
          |                                   |
 [ Stacja Windows ]                  [ Serwer usług ]
          |                                   |
 [ Kontroler domeny ]              [ Baza danych / usługi ]
```

Kolejne moduły wykorzystują to samo środowisko lub jego rozszerzone wersje.
