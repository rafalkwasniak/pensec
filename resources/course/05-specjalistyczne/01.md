## Sieć bezprzewodowa i uścisk WPA2

Sieć w standardzie 802.11 rozgłasza swoją obecność ramkami typu beacon, a klienci uwierzytelniają się w sieci WPA2 przez czteroetapową wymianę kluczy (*4-way handshake*). Wymiana ta przenoszona jest w ramkach EAPOL i, w odróżnieniu od samego hasła, pojawia się w eterze przy każdym przyłączeniu klienta. Brak fizycznej izolacji medium pozwala rejestrować ruch w zasięgu anteny bez połączenia z siecią.

## Tryb monitora

Rejestracja ruchu bezprzewodowego wymaga przełączenia interfejsu w tryb monitora, odbierający wszystkie ramki w zasięgu, a nie tylko kierowane do niej.

```bash
sudo ip link set [INTERFACE] down
sudo iw dev [INTERFACE] set type monitor
sudo ip link set [INTERFACE] up
```

Pierwsze i trzecie polecenie wyłączają oraz ponownie włączają interfejs, ponieważ zmiana trybu wymaga nieaktywnego łącza. Środkowe polecenie `iw dev ... set type monitor` przełącza kartę w tryb monitora, odbierający wszystkie ramki w zasięgu. W miejsce `[INTERFACE]` wpisuje się we wszystkich trzech poleceniach bezprzewodowy interfejs sieciowy. Przełączanie między kanałami, poleceniem `iw dev [INTERFACE] set channel [N]`, pozwala objąć nasłuchem kolejne częstotliwości.

Tryb monitora sam w sobie jest biernym nasłuchem i nie wysyła ramek do sieci. Sposób zbierania ramek uwierzytelniania oraz granice tego, co z nich wynika, opisuje kolejna lekcja.
