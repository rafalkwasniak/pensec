## Adres MAC jako słaba tożsamość

Adres sprzętowy MAC jest deklarowanym i zmiennym identyfikatorem interfejsu, a nie dowodem tożsamości. Mimo to część infrastruktury traktuje go jako podstawę dostępu.

## Mechanizm MAB

Gdy urządzenie nie obsługuje uwierzytelniania 802.1X, na przykład drukarka sieciowa lub telefon, przełącznik dopuszcza je do sieci wyłącznie na podstawie adresu MAC. Mechanizm ten nosi nazwę *MAC Authentication Bypass* (MAB). Słabość polega na tym, że zaufanie opiera się na łatwym do podrobienia identyfikatorze.

## Granica oceny: obserwacja, nie podszycie

W ocenie oznacza to konkretne zadanie rozpoznawcze: ustalić, jakie urządzenia są dopuszczane na podstawie samego adresu MAC, i odnotować, że ta forma kontroli jest słaba. Adresy kandydujące zbiera się pasywnie z ruchu segmentu, a prefiks `OUI` wskazuje typ sprzętu, co pomaga rozpoznać urządzenia dopuszczane przez MAB. Zakres oceny kończy się na tej obserwacji. Podszycie się pod dopuszczone urządzenie, czyli faktyczne obejście kontroli dostępu, jest działaniem o szerszych uprawnieniach i nie wchodzi w zakres tego rozpoznania. Samo zebranie adresów nie jest obejściem kontroli.

## Zmiana adresu MAC jako maskowanie

Zmiana własnego adresu MAC bywa stosowana jako działanie maskujące, na przykład w celu ograniczenia śladu operatora w sieci. Jest to działanie aktywne, chwilowo rozłącza interfejs i domyślnie pozostaje wyłączone.

```bash
sudo ip link set dev [INTERFACE] down
sudo macchanger -A [INTERFACE]
sudo ip link set dev [INTERFACE] up
```

`[INTERFACE]` lokalny interfejs sieciowy. Parametr `-A` nadaje losowy adres z puli istniejącego producenta.

Ograniczenie ryzyka związanego z zaufaniem do adresu MAC polega na stosowaniu pełnego uwierzytelniania 802.1X tam, gdzie to możliwe, oraz na ścisłym ograniczeniu listy adresów dopuszczanych przez MAB.
