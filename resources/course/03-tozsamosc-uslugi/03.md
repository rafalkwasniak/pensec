## Wyszukiwanie plików wysokiego ryzyka

Wewnętrzne serwery plików gromadzą przez lata dokumenty, kopie zapasowe i skrypty, wśród nich zapomniane pliki z poświadczeniami. Ręczny przegląd jest niewykonalny, dlatego przeszukanie wielu udziałów automatyzuje się, porównując nazwy plików z listą wzorców wysokiego ryzyka.

## Przeszukanie wzorcem

```bash
sudo smbmap -H [IP] -u null -p '' -R --depth 3 -A '(kdbx|ovpn|unattend|config|txt)'
```

`[IP]` adres hosta z usługą SMB. Parametry `-u null -p ''` zestawiają sesję anonimową, `-R --depth 3` przeszukują drzewo katalogów do zadanej głębokości, `-A` dopasowuje nazwy do wzorca.

```text
dane      READ ONLY
  .\kopie\unattend.xml
  .\skrypty\deploy.config
backup    READ ONLY
  .\vpn\profil.ovpn
```

## Od nazwy do dowodu

Dopasowane nazwy, takie jak baza haseł `kdbx`, plik `unattend.xml` czy profil `ovpn`, są tropami, a nie dowodem. Rzeczywistym materiałem dowodowym jest dopiero zawartość pliku, a jej odczyt i ocena należą do dalszego, uzgodnionego etapu. Trafienie wzorca nie gwarantuje, że plik zawiera aktualne poświadczenia. Ograniczenie ryzyka polega na usunięciu dostępu anonimowego oraz na okresowym przeglądzie udziałów pod kątem wrażliwych artefaktów.
